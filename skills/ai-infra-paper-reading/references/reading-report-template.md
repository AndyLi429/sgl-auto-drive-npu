## 4. Design

说明系统或算法如何落地：

- 数据路径：输入、关键状态、输出。
- 控制路径：触发条件、调度/决策、回退或边界行为。
- 实现要点：数据结构、并行策略、通信、内存或 kernel 改动。
- 正确性与不变量：方案必须维持什么语义、精度或 SLO？

## 5. Evaluation

| 项目 | 论文证据 | 公平性/解释注意点 |
|---|---|---|
| 实验环境 | 硬件、节点、互连、模型、软件版本、精度 | 是否与 baseline 一致？ |
| 工作负载 | 到达过程、并发、输入/输出长度、数据集、SLO | 是否代表目标线上场景？ |
| Baseline | 名称、版本、关键配置 | 是否调到相同资源与目标？ |
| Metric | TTFT / TPOT / throughput / p99 / cost 等定义 | 统计口径和采样窗口是什么？ |
| 主要结果 | 带单位的绝对值与相对变化 | 结果在哪些条件下成立？ |
| 消融 | 移除哪个组件、指标如何变化 | 是否隔离了关键机制？ |
